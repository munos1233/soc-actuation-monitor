# SOC actuation monitor

Paper repository for transactional evidence integrity on agent-actuated writes.

The manuscript is `paper/cs-submission/`. Reproduction commands are in `REPRODUCE.md`.

```bash
make paper-eval-up
make paper-eval-quick
make paper-eval-down
```

`paper-eval-quick` does not need an API key. The TheHive sandbox is separate and is not pooled with the 57-case suite.
